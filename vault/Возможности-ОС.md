# Возможности ОС (каталог для примитивов)

> Разведка устройства **2026-10-16** (Sailfish OS 5.1.0.11 «Pispala», Xperia 10 IV, aarch64,
> пользователь `defaultuser` uid 100000). Снято через `dbus-send`-интроспекцию обеих шин.
>
> **Назначение:** полный список того, что **ОС отдаёт через стабильные интерфейсы**. Что из этого
> станет примитивами — решается на этапе разработки (Jack). См. принцип в [[ADR-0010-примитивы-через-ОС]].
>
> Статус доступа: ✅ — реально вызывается `defaultuser`; 🔶 — интроспекция открыта, запись не
> проверялась (может требовать polkit/группу); ❔ — методы не видны в интроспекции.

## Как снималось

- Имена обеих шин: `dbus-send ... org.freedesktop.DBus.ListNames`.
- Методы: `dbus-send --system|--session --dest=… <path> org.freedesktop.DBus.Introspectable.Introspect`.
- Проверка вызова: реальный вызов read-метода.

`defaultuser` состоит в группах: `sailfish-messages`, `sailfish-phone`, `timed`, `sailfish-datetime`,
`sailfish-alarms`, `bluetooth`, `audio`, `media`, `input`, `sailfish-system`, `ssu`.

## 4. Связь — connman, BlueZ, wpa_supplicant

| Технология | path | Powered |
|---|---|---|

| GPS | `/net/connman/technology/gps` | ✅ `true` |
| Ethernet | `/net/connman/technology/ethernet` | ✅ `false` |

→ **вкл/выкл WiFi, сотовая, BT, GPS**; оффлайн; подключение к сервисам.

## 12. Штатные утилиты ОС (для builtin-примитивов)

Доступно `defaultuser`: `dbus-send`, `pactl`, `python3` 3.11.15 (+`sqlite3` модуль, +gobject),
`perl`, `awk`/`sed`/`busybox`, `sqlite` через python3.
**Нет:** настоящего bash, lua/luajit, node, ruby, `sqlite3` CLI, `qdbus`, `gdbus`, `busctl`.

## Не берём / открыто

- **Фонарь (torch)** — torch-LED нет; вспышка = камера-вспышка (железо-специфично) → вне каталога
  (см. принцип [[ADR-0010-примитивы-через-ОС]]).
- **Профили/DND** (`com.nokia.profiled`) — в интроспекции только сигнал `profile_changed`; методы
  не видны ❔. Надо копать (возможно, другой сервис/путь).
- **Локация/GPS** — отдельного GeoClue-сервиса в списке имён нет; GPS-технология у connman есть,
  координаты — открыто.
- **Медиауправление** — MPRIS-плееров нет; `org.maemo.Playback.Manager` не интроспектируется ❔.
- **Запись (🔶) требует проверки** — доступ к методам для записи может гейтиться polkit/группой.

См. [[Навыки]], [[ADR-0010-примитивы-через-ОС]], [[Безопасность]], [[Архитектура]].
