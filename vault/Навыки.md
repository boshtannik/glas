# Навыки (команды)

> Состояние (2026-10-16): **дизайн, пересмотрен.** Модуля `src/skills/` и `SkillRegistry`
> ещё нет; `SkillsPage.qml` — скелет. Решение об исполнении — [[ADR-0007-исполнение-навыков]].
> Реализовано пока только встроенная «память» (`memory.*`, см. [[Контекст-и-память]]).

«Навык» = **объявленное действие**: манифест (`manifest`) + реализация. Пользователь может
включать/выключать и добавлять свои (см. [[Шаблоны-команд]]).

## Главный принцип: декларативно, без произвольного кода

**Никакого исполнения чужого кода.** `sh`/`python3` скрипты из `.gskill`/URL **не запускаем**
(вектор малвари, невалидируемо). Вместо этого — **один трейт `Skill`** и две реализации,
неразличимые для ядра:

```rust
trait Skill {
    fn manifest(&self) -> Manifest;
    fn validate(&self, params: &Params) -> Result<()>;
    fn execute(&self, params: &Params, ctx: &Ctx) -> Result<Outcome>;
}
```

- **`BuiltinSkill`** — на Rust, вкомпилирован (таймер, SMS, громкость, фонарь, открыть
  приложение…). Тестируется на хосте, безопасно по построению. Реализуются **через интерфейсы
  ОС**, не через железо — см. [[ADR-0010-примитивы-через-ОС]]; полный инвентарь доступного —
  [[Возможности-ОС]].
- **`DeclarativeSkill`** — собирается **из манифеста** и выполняет один примитив:
  `dbus`-вызов / `open`-URI / **композицию** builtin'ов. Кода нет — только данные.

Одни и те же данные (`manifest`) питают **три** вещи: каталог интентов для промпта,
валидацию слотов и исполнение.

## Манифест (декларативный)

```json
{
  "schema": 1,
  "id": "set_timer",
  "name": "Таймер",
  "description": "Поставить таймер на N минут",
  "examples": ["поставь таймер на 5 минут", "таймер 10 мин"],
  "params": {
    "duration_seconds": { "type": "int", "required": true, "min": 1 }
  },
  "do": [
    { "dbus": { "bus": "session", "dest": "com.nokia.time", "path": "/", "iface": "…", "method": "…", "params": { "seconds": "%duration_seconds" } } }
  ],
  "undo": [ { "dbus": { "…": "…" } } ],
  "danger": false
}
```

- **`do`** — список примитивов (композиция): `dbus` / `open` / `builtin`. Позволяет собирать
  рецепты из готовых действий без кода.
- **`%name`** — подстановка слота **в данные** (`dbus`-аргумент, URL), не в shell-строку.
- **`undo`** — обратная композиция (кнопка «Отменить»).
- **`danger`** — декларативный флаг подтверждения (см. [[Безопасность]]).

## Валидация слотов

- Типы из `params` (`int`, `float`, `bool`, `enum`, `string`), диапазоны, обязательность.
- Неизвестный интент / невалидные слоты → навык НЕ запускается, ассистент честно говорит
  «не понял / не хватает данных».
- Валидация **декларативная** и не зависит от «языка исполнения» (произвольного кода нет).

## Реестр навыков (`SkillRegistry`) — единый источник правды

```
~\ .local/share/harbour-glas/skills/<id>/manifest.json (+ ассеты)   ← пользовательские
/usr/share/harbour-glas/skills/<id>/manifest.json                   ← builtin (в RPM)
```

- Реестр при старте (и при изменении) сканирует обе папки, парсит каждый `manifest.json`,
  строит индекс по `id`. Бэд-запись пропускается с понятным сообщением — реестр не падает.
- **Вкл/выкл** — список отключённых `id` в настройках (файлы не удаляем).

## Источники навыков (добавление без правки кода)

| Источник | Как | Куда |
|---|---|---|
| builtin | в RPM | `/usr/share/harbour-glas/skills/` (read-only) |
| пользовательские | «+» → выбрать папку | `~/.local/share/harbour-glas/skills/` |
| скачанный файл | «+» → выбрать `.gskill` | распаковка в пользовательскую папку |
| по URL | «+» → ссылка → скачать → проверка `sha256` → **ревью-диалог** → установить | туда же |

## Примеры для MVP (builtin)

- **Таймер/будильник** — D-Bus к `timed` (`timedclient-qt5` как ориентир).
- **Чтение SMS** — `commhistory.db` (sqlite; `python3-sqlite` есть по умолчанию) — builtin
  (не пользовательский скрипт!).
- **Громкость/фонарь/открыть приложение** — dbus / open.
- **Отправка SMS** — отдельно и осторожно, `danger` (см. [[Безопасность]], [[Открытые-вопросы]]).

## Служебные (встроенные) навыки

- **`memory.set(key, value)`** — запись факта в профиль (`~/.local/share/harbour-glas/profile.json`,
  см. [[ADR-0006-память-предпочтения]]). Всегда требует подтверждения в UI (защита от
  промпт-инъекций). Нельзя удалить из каталога.
- **`memory.forget(key)`** — удаление факта (тоже с подтверждением).
- Чтение профиля отдельным навыком не нужно: профиль всегда в system-prompt.

## Журнал и undo

- Каждое выполнение пишется в SQLite (`id`, навык, слоты, результат, время).
- `undo` — обратная композиция; кнопка «Отменить» на баббле команды.
- **Cancel** отменяет текущую обработку (прерывание инференса), не путать с undo.
