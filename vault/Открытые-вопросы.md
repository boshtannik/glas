# Открытые вопросы

> Обновлено 2026-10-15.

1. **Запись при свёрнутом окне (Sailfish).** booster/suspend/sailjail могут мешать.
   Нужен прототип: удержание аудио-ресурса, корректный запуск, реакция на блокировку экрана.
2. **Отправка SMS.** Как надёжно слать: bash → DBus/telephony (`telepathy`/`commhistory`)
   или `kind: qml`. Чтение SMS — через `commhistory.db` (sqlite), это проще.
   Таймеры/будильники — `timed` (D-Bus). Проверить интерфейсы на устройстве.
3. **Гарантия формы JSON без GBNF** (этап 4): промпт+парсер+retry / ручной
   constrained-decoding / `llguidance`. **Решение не принято.** См. [[ADR-0002-llm-gbnf]],
   [[Промпты]].
4. **Скорость инференса (candle)** на Snapdragon 695: подобрать модель/квантование,
   измерить задержку и потребление; пороги [[Автономность]].
5. **Точный расчёт влезаемости моделей** (static+dynamic): формула и пороги
   (базовая версия уже в `llm.rs`, см. [[Модели-и-каталог]]).
6. **Привилегии/sailjail:** какие пермишены нужны (микрофон и т.д.), влияние на фон;
   сейчас `.desktop` с `Sandboxing=Disabled` — вернуться до Harbour-валидации.
7. **Имя пакета и домен:** `harbour-glas`, `ru.<author>.glas`? Организация (OpenRepos/Harbour).
8. **Движок TTS** — piper (как референс) или иной; русский голос.
9. **Примеры для few-shot** и полный список интентов MVP.
10. **Хранение истории** — схема SQLite и связь «ход ↔ действие ↔ undo».
11. **Проверка версии навыков** — точные правила `app_min/app_max`.
12. **Размер бинаря/пакета** — debug ~297 МБ (с debuginfo), release RPM ~31.6 МБ;
    при релизе собирать release без debuginfo, разобраться с символами.

См. [[План]], [[Сборка]], [[Безопасность]].
