# Флоу UI (сквозной сценарий)

> Состояние (2026-10-15): **дизайн.** Реализован только базовый PTT-цикл на странице
> диалога (запись → STT → ответ → опциональная озвучка). Нет VAD-автостопа, обложки-
> микрофона, ленты бабблов, интентов/навыков, нотификаций. См. [[UI-Страницы]].

## Первый запуск (нет настроек/моделей)

Если не заданы нужные настройки (нет STT/TTS или thinking-модели) — **первым делом отправляем
пользователя на страницу [[Настройки]]** (или страницу Голосовые модели), а не даём жать микрофон
впустую. Пока ассистент не готов — это видно из состояния экрана.

## Сценарий A — быстрый (обложка)
```
Приложение свёрнуто → на обложке кнопка-микрофон (idle, модели выгружены)
  удержание (push-to-talk): идёт запись
  отпускание кнопки → ход НАЧИНАЕТСЯ (кнопка «стоп» не нужна)
  → обработка: STT → LLM → валидация → навык → результат
  → озвучка/нотификация → выгрузка моделей → снова idle
```
Во время обработки на обложке — кнопка **Отмена** (kill child + прерывание инференса).
Ход стартует **на отпускании** кнопки push-to-talk. VAD-автостоп — опционально, позже.
**Перебивание:** повторное удержание PTT во время `Thinking`/`Speaking` прерывает текущее
(глушим TTS/инференс) и начинает новую запись — то же, что кнопка «Отмена».
См. [[ADR-0012-диалог-контекст-выход-чтение]].

## Сценарий B — полное приложение (страница «Диалог»)
```
[ Диалог ]
  лента бабблов:
    Пользователь: «поставь таймер на 5 минут»
    Навык:        set_timer · таймер 5 мин · [Отменить]
    Ассистент:    «Готово, таймер на 5 минут.»
  ────────────────────────────────────────────
  [ 🎤 удержание кнопки (push-to-talk) ]   [ Отмена (во время обработки) ]
```

## Состояния главного экрана
```
idle → recording → processing → (выполнение) → answered → idle
                   └─ cancel ─┘
```
- **recording:** идёт, пока удерживается кнопка push-to-talk (пульсация, таймер).
- **processing:** индикатор «распознаю / думаю / выполняю», кнопка «Отмена».
- **не понял / нет навыка:** баббл «Не понял» либо «Такого навыка нет / он выключен»
  + предложение повторить/открыть [[Навыки]].
- **нужны данные (slot-filling):** ассистент задаёт уточняющий вопрос; если навык умеет **читать**
  кандидатов — вопрос со списком («У тебя 3 будильника: 7:00, 8:00, 9:00. Какой удалить?»); ждёт
  ответ (см. ниже).
- **danger-навык:** диалог подтверждения перед выполнением; **ждём без таймаута**, ответ —
  кнопкой или повторным удержанием push-to-talk («да»/«нет»).
- **выход в новый навык:** если в ожидании (подтверждение/уточнение) пользователь говорит **не
  ответ, а другую команду** — сессия **выходит**, реплика резолвится как новый ход (навык
  найден/включён → исполняем; иначе → «такого навыка нет / он выключен»). См.
  [[ADR-0012-диалог-контекст-выход-чтение]].
- **перебивание:** повторное нажатие PTT прерывает обработку/озвучку и начинает новую запись.

## Напоминание об ограниченной памяти
Когда ход выпадает из [[Контекст-и-память|скользящего окна]], в ленте — приглушённая строка:
> 🧠 Память ограничена: более раннее забыто.

Один раз при первом запуске — короткая заметка: ассистент локальный/искусственный,
помнит ограниченное число слов, давнее удержать физически не может.

## Уведомления
- Запрос подтверждения — нотификация Silica + звук.
- Готовность/результат при свёрнутом окне — дзинь + нотификация.
