# Сборка

## Модель работы
Разработка ведётся **здесь (на телефоне, через opencode = mason)**. Сборка — на ПК,
где развёрнут Docker-образ сборки. Поток:
```
здесь: git commit + git push
ПК:    git pull
ПК:    ./mbuild.sh  (Docker sailo-rs + mb2)  → harbour-glas-*.aarch64.rpm
телефон: установка RPM / deploy бинаря
```
SSH-креды и доступ к билд-машине — от пользователя (позже).

## Референс: как устроена сборка в mason
- `mbuild.sh` — `docker run` образа `registry.gitlab.com/whisperfish/sailo-rs/rust-aarch64-5.1.0.11:sfos-5-1`,
  монтирует исходники только для чтения и кэш `cargo`, внутри — `mb2 ... build`.
- `rpm/harbour-opencode.spec` — Rust-бинарь + движки в `/usr/libexec`, `.desktop`, hicolor,
  `BuildRequires: rust cargo pkgconfig(Qt5...) sailfishapp`, `%global __strip /bin/true`.
- Кросс-сборка/нативная для aarch64 в образе; `.cargo/config.toml` задаёт linker/env.
- `scripts/deploy.sh` — `scp` бинаря на телефон; `scripts/build.sh` — `cargo build`.

## Что адаптируем для Glas
- Имя проекта `glas`, пакет `harbour-glas`, спека `rpm/harbour-glas.spec`.
- Движки: `whisper-cli` (собирается из whisper.cpp, патч `--audio-ctx`) и `piper`
  (готовый aarch64-билд в кэше). Каталог `assets/models.json` — с ролью `llm`.
- Добавляем сборку llama.cpp/llama-cpp-2 для инференса GGUF.
- ВАЖНО: свежий Rust/edition2024 может не завестись в старом sfdk — используем
  Docker-образ сборки (в нём современные компиляторы).

## Сборка на самом телефоне (fallback/эксперимент)
- В repo jolla есть `rust`/`cargo` 1.75, `gcc` 13.4, `cmake`, `make`, `pkgconfig`,
  `qt5-qtdeclarative-devel`. Можно попробовать, НО:
- **Корень `/` почти полон (~632 МБ свободно)** — установка тулчейна рискованна.
  Поэтому основной путь — ПК.

## Проверки
- `cargo check` → `cargo clippy` → `cargo fmt --check` → `cargo test` (по [[Структура]]).
- `qmllint`/`qmlformat` для QML (если доступны).
- Смок-запуск на телефоне: тап по иконке (правильный env от lipstick), не из ssh.
- После деплоя чистить QML-кэш, если менялся QML (из опыта референса).
