# Архитектура

Один процесс: Rust-бинарь запускает QML-движок (через `sailors`/`sailfishapp`),
регистрирует `AppBridge` как QObject и отдаёт корневой QML. Как в референсе mason.

## Слои
```
QML (Silica UI)
  │  qt_method! / qt_property! / qt_signal!   (qmetaobject-rs)
  ▼
AppBridge (bridge/app.rs)
  │  очереди Arc<Mutex<..>>, воркер пишет shared, QML опрашивает (poll)
  ▼
Rust worker (поток)
  ├── audio      — recorder/player/stt/tts/vad/voice
  ├── intent     — модель GGUF (llama.cpp), промпт + GBNF, load/unload
  ├── skills     — реестр, exec (script|dbus|qml), undo
  ├── history    — SQLite (диалог, действия, откат)
  └── settings   — JSON
```

## Поток обработки одного запроса
```
тап mic → запись (cpal) → WAV 16k mono
  → VAD-автостоп | ручной стоп
  → STT (whisper-cli) → текст
  → intent (llama.cpp, GBNF) → {intent, params, reply} | unknown
  → skills.validate(intent, params) → skills.exec(...)
  → результат → history.append(...) → бабл команды в UI
  → TTS (piper) / нотификация
  → unload моделей (idle)
```

## Модули и ответственность
- **bridge** — единственная точка Rust↔QML. Никаких Qt-сигналов из чужих потоков:
  воркер пишет в `Arc<Mutex<..>>`, QML вызывает `poll`/`drain`.
- **intent** — менеджер одной активной LLM-модели. `mmap` без `mlock`; держим mmap,
  а не всю модель в heap; выгружаем по idle. См. [[Автономность]].
- **skills** — реестр. `exec` запускает дочерний процесс (script), шлёт D-Bus (dbus),
  или просит QML выполнить действие (qml). Таймаут + kill.
- **history** — персист для UI и для undo. В промпт уходит только компактная выжимка.
- **audio** — переиспользуется из референса практически as-is.

## Протокол (cmd.rs)
`enum Cmd` с `#[serde(tag = "cmd", rename_all = "snake_case")]`. QML отправляет
`{"cmd": "<name>", ...}`. Один источник — Rust; match исчерпывающий (компилятор ловит).
Примерные варианты: `Listen`, `Stop`, `Cancel`, `Undo { id }`, `ClearDialog`,
`SkillList`, `SkillEnable { id, on }`, `SkillImportFile { path }`, `SkillImportUrl { url }`,
`SkillDelete { id }`, `VoiceDownload { id }`, `VoiceSelect { id }`, `GetSettings`, `SaveSettings { value }`.

## Вендор из референса
`vendor/qmetaobject-sfos-rs` — форк qmetaobject-rs под Sailfish; `vendor/sailors` —
обёртка `SailfishApp`. Оставляем как есть. См. [[ADR/0001-стек]], [[Сборка]].
