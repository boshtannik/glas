# Настройки

> Состояние: сверено с кодом 2026-10-15. Реальные ключи — в `settings.rs`.
> Отдельного UI-редактора пока НЕТ: `GeneralSettingsPage.qml` — скелет-заглушка,
> значения меняются прямо в файле.

Персист: `~/.config/harbour-glas/settings.json` (serde, атомарная запись tmp+rename;
отсутствующий/битый файл → дефолты). Отдельная структура `Settings` (не dconf).

## Реализованные ключи (settings.rs)
| Ключ | Тип | Дефолт | Назначение |
|---|---|---|---|
| `language` | string | `"ru"` | язык UI/распознавания |
| `max_turns` | u32 | `8` | ходов в скользящем окне (см. [[Контекст-и-память]]; пока не используется пайплайном) |
| `max_tokens` | u32 | `700` | лимит контекста (idem) |
| `tts_mode` | string | `"button"` | `off` \| `button` \| `auto` |
| `idle_unload_secs` | u64 | `120` | простой до выгрузки модели из RAM (0 = никогда); используется watchdog'ом в `infer.rs` |
| `stt_model` | string | `""` | явный путь к whisper GGML (пусто = авто) |
| `stt_threads` | u32 | `4` | потоков для `whisper-cli` |

## Что ещё запланировано (в заметках-черновиках ранее)
- Голос: выбор активной asr/tts-модели, режим TTS, язык (частично есть в store, не в `Settings`).
- Пробуждение/VAD-чувствительность/макс. длина записи.
- Уровень подтверждений для `danger`-навыков.
- Порог `MemAvailable` для загрузки модели.
- Язык интерфейса (правило референса: активен только при 100% переводе).

## Зависимые настройки (правило из референса, пока не реализовано)
- Опции TTS активны только при скачанной tts-модели; STT — при скачанной asr-модели.
- Блокированный пункт — серый + «почему» + ссылка на [[Модели-и-каталог]].

См. [[Модели-и-каталог]], [[Контекст-и-память]].
