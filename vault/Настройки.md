# Настройки

Персист: `~/.config/harbour-glas/settings.json` (serde). Интерфейсные настройки — dconf,
как в референсе (не смешивать с протоколом).

## Ключи (черновые)
- **Голос (STT):** активная asr-модель, язык распознавания.
- **Голос (TTS):** активная tts-модель, режим (`off` | `button` | `auto`).
- **Пробуждение:** тап по обложке; VAD-чувствительность; макс. длительность записи.
- **Контекст:** `max_turns`, `max_tokens` (скользящее окно). См. [[Контекст-и-память]].
- **Подтверждения:** уровень для `danger`-навыков.
- **Модели/ресурсы:** idle-timeout выгрузки; порог `MemAvailable` для загрузки модели.
- **Язык интерфейса** (язык активен только при 100% переводе — правило из референса).
- **Навыки:** список с вкл/выкл; импорт/экспорт.

## Зависимые настройки (правило из референса)
- Опции TTS активны только при скачанной tts-модели.
- Опции STT — только при скачанной asr-модели.
- Блокированный пункт — серый + «почему» + ссылка на [[Модели-и-каталог]].

## «+» для импорта навыка
В окне [[Навыки]] / настройках: плюс → файл или URL → ревью → подтверждение.
См. [[Шаблоны-команд]].
