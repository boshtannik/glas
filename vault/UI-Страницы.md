# UI: страницы и навигация

Silica-карусель, свайпы, без кнопок в шапке (палец не тянется вверх).

## 1. Диалог (главная рабочая страница)
- Крупная кнопка-микрофон (тап = диктовка; во время обработки = «Отмена»).
- Лента бабблов:
  - **Bubble** (пользователь) — распознанный текст.
  - **CommandBubble** — что сделал ассистент: имя навыка, человекочитаемое описание,
    слоты, результат, кнопка **Отменить**.
  - **Bubble** (ассистент) — текст ответа; кнопка 🔉 повтора озвучки.
- Приглушённые системные строки (напр., «память ограничена»).

## 2. Настройки
Пробуждение, VAD-чувствительность, TTS/голос, уровень подтверждений, язык,
idle-выгрузка моделей, порог RAM для загрузки моделей. См. [[Настройки]].

## 3. Голосовые модели
Каталог (как в референсе): секции по ролям (Распознавание / Синтез / Язык-модель),
фильтр по языку, скачать/выбрать/удалить, прогресс, метки `fits/slow`.
См. [[Модели-и-каталог]].

## 4. Навыки
- Список навыков: имя, описание, `kind`, вкл/выкл, [поделиться] (экспорт `.gskill`).
- **«+»** в шапке → импорт:
  - из файла на устройстве (файловый пикер), или
  - по прямой ссылке (скачать → ревью → проверка версии/целостности → подтверждение).
- Ревью показывает содержимое команды/скрипта и что она будет делать.
См. [[Навыки]], [[Шаблоны-команд]], [[Безопасность]].

## Навигация
- Свайп влево/вправо между страницами (карусель).
- PullDown — только там, где нет конфликта со скроллом.
- Обложка — отдельный быстрый сценарий (микрофон).

См. [[Флоу-UI]].
