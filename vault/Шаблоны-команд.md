# Шаблоны команд и шэринг

> Состояние (2026-10-15): **дизайн, НЕ реализовано** (нет экспорта/импорта `.gskill`,
> нет `skills/`). См. [[Навыки]].

Пользователь настраивает навык и **экспортирует файл**, которым делится (например, на форуме).
Другие импортируют его через кнопку **«+»** в окне [[Навыки]] — из файла или по прямой ссылке.

## Формат файла `.gskill`
Один самодостаточный файл (JSON; крупные скрипты — можно как base64/архив внутри):
```json
{
  "schema": 1,
  "name": "Таймер",
  "id": "set_timer",
  "description": "...",
  "author": "@user",
  "version": "1.0.0",
  "app_min": "0.1.0",          // совместимость с версией ассистента
  "app_max": "",
  "kind": "script",
  "params": { "...": {} },
  "script": "#!/bin/sh\n...",   // сериализованное тело команды
  "undo": "#!/bin/sh\n...",
  "danger": false,
  "sha256": "…"                 // целостность содержимого
}
```

## Импорт
1. Источник: файл на устройстве **или** URL.
2. Скачать/прочитать → проверить `sha256`, `schema`, `app_min/app_max` (совместимость).
3. **Диалог-ревью:** показать имя, автора, что делает, содержимое скрипта/команды, `kind`, `danger`.
4. Явное подтверждение → сохранить в `~/.local/share/harbour-glas/skills/<id>/`.
5. Несовместимая версия → предупреждение/блок (см. [[Безопасность]]).

## Экспорт
- Кнопка «поделиться» у навыка → собрать `.gskill` → отдать через Sailfish Share/TransferEngine
  или сохранить в файл.

## Каталог шаблонов (следующий шаг)
- Аналог каталога моделей: подписка на реестр шаблонов по URL, обновление, рейтинг.
- Не в MVP; сначала файл+URL.

## Совместимость версий
- `app_min`/`app_max` сверяются с версией Glas; при несоответствии — понятная ошибка
  («нужна версия ≥ X»), чтобы навыки не ломали ассистент.
