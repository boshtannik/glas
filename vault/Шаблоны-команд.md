# Шаблоны команд и шэринг

> Состояние (2026-10-16): **дизайн, пересмотрен.** См. [[ADR-0007-исполнение-навыков]]:
> никакого исполняемого кода в разделяемых файлах. `.gskill` = **декларативный навык/рецепт**.
> Экспорт/импорта пока нет; `skills/` нет.

Пользователь настраивает действие и **экспортирует файл**, которым делится (например, на
форуме). Другие импортируют его через «+» в окне [[Навыки]] — из файла или по ссылке.

## Что именно шэрим: не код, а рецепт

Пользователь делится **отображением «фраза → действие»**, а не скриптом. Значит `.gskill`
описывает **декларативную привязку** (dbus/open/композиция builtin) — её видно в ревью,
её можно валидировать, она безопасна по построению.

## Формат файла `.gskill`

Самодостаточный **JSON** (склоняемся к JSON-first; крупные ассеты — base64/вложение):

```json
{
  "schema": 1,
  "id": "put_on_the_kettle",
  "name": "Вскипятить чайник",
  "description": "Таймер 5 минут + фонарь",
  "examples": ["поставь чайник", "вскипяти чайник"],
  "author": "@user",
  "version": "1.0.0",
  "app_min": "0.1.0",
  "app_max": "",
  "params": {},
  "do": [
    { "dbus": { "bus": "session", "dest": "com.nokia.time", "method": "…", "params": { "seconds": 300 } } },
    { "builtin": { "id": "set_flashlight", "params": { "on": true } } }
  ],
  "undo": [],
  "danger": false,
  "sha256": "…"
}
```

- **`do`** — композиция примитивов (`dbus` / `open` / `builtin`); слоты подставляются в данные
  (`%name`), не в shell.
- **`undo`** — обратная композиция.
- **`sha256`** — целостность содержимого.

## Импорт

1. Источник: файл на устройстве **или** URL.
2. Скачать/прочитать → проверить `sha256`, `schema`, `app_min`/`app_max` (совместимость).
3. **Диалог-ревью:** имя, автор, что делает, **композиция `do`**, `danger`.
4. Явное подтверждение → сохранить в `~/.local/share/harbour-glas/skills/<id>/`.
5. Несовместимая версия → предупреждение/блок (см. [[Безопасность]]).

## Экспорт

- Кнопка «поделиться» у навыка → собрать `.gskill` → отдать через Sailfish Share/TransferEngine
  или сохранить в файл.

## Каталог шаблонов (следующий шаг)

- Аналог каталога моделей: подписка на реестр рецептов по URL, обновление, рейтинг.
- Не в MVP; сначала файл + URL.

## Совместимость версий

- `app_min`/`app_max` сверяются с версией Glas; при несоответствии — понятная ошибка
  («нужна версия ≥ X»), чтобы навыки не ломали ассистент.
