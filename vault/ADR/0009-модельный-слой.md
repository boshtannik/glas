# ADR-0009: Модельный слой — отдельный крейт за трейтом-бэкендом

**Статус:** принято · **Дата:** 2026-10-16
**Связано:** [[Архитектура]], [[Модели-и-каталог]], [[ADR-0001-стек]], [[ADR-0002-llm-gbnf]]

## Контекст

Загрузка и инференс моделей заперты в `infer.rs` внутри основного крейта и **жёстко завязаны
на типы `candle`**: `quantized_*::ModelWeights`, `gguf_file::Content`, `TokenizerFromGguf`,
`LogitsProcessor::from_sampling`, плюс глобальный синглтон
`static MODEL: OnceLock<Mutex<Option<Loaded>>>`. `candle` — чужой крейт; если он не устроит
(скорость/поддержка архитектур/размер), замена будет хирургической, потому что его типы
протекли в наш код и в форму API (`infer::generate(prompt, max_new, temperature)`).

Дополнительно: основной крейт `glas` на хосте не собирается (тянет `qmetaobject`/`sailors`),
поэтому **тестировать модельный слой можно только в отдельном крейте** без Qt/sb2. `candle`
и `reqwest` — чистый Rust, билдятся и тестируются на хосте.

## Решение

1. **Выделить модельный слой в автономный крейт** (`glas-models`) без зависимости от Qt/sb2 —
   по образцу `glas-memory` (и `opencode-proto`/`voice-engine` в opencode).
2. **Охват — весь модельный слой:** каталог + скачивание + загрузка + инференс.
3. **Трейт-бэкенд инференса** (например `TextGen { load / generate / unload }`) — `candle` за
   «швом». Программа зависит от трейта, а не от `candle`. Замена бэкенда не трогает остальной код.
4. **Тесты на хосте:**
   - mock-бэкенд (проверка оркестрации без реальной модели);
   - вынесенная чистая логика: диспатч `general.architecture → loader`, форматирование
     ChatML-промпта, выбор стоп-токенов, парсинг HF-ответов и числа параметров из имени,
     порядок предпочтения квантов (`pick_gguf`), формула бейджа влезаемости.

## Последствия

+ Бэкенд меняется за «швом» — можно заменить `candle`, не переписывая ядро.
+ Модельный слой реально покрывается тестами на хосте.
+ Единообразие с opencode: самодостаточные крейты с тестами.
− `candle` всё ещё тянется как зависимость крейта (размер сборки не уменьшается).
− Разовый вынос кода `infer.rs`/`llm.rs` в новый крейт и правка путей.

## Реализовано (2026-10-17)

«Шов» уже есть в ядре (`glas-core/src/engine.rs`): трейт `TextGen { load / generate / unload }`
(`load`/`unload` — дефолтные no-op, чтобы фейки и скриптовые генераторы реализовывали только
`generate`) плюс `SpeechToText`/`TextToSpeech` и фейки для host-тестов. Реальные бэкенды
(`candle`, whisper.cpp, piper) подключаются позже в отдельном `glas-models` за этим швом.
