# ADR-0001: Стек — Rust + QML/Silica, один процесс

**Статус:** принято · **Дата:** 2026-10-11

## Контекст
Нужно нативное приложение Sailfish с локальным аудио, инференсом и системными действиями,
при минимальном потреблении в фоне.

## Решение
- Rust-бинарь + QML (Silica), один процесс.
- Связь Rust↔QML через `qmetaobject-sfos-rs` (вендорим из референса mason).
- Обёртка `sailors`/`sailfishapp` для бутстрапа QML.
- `cmds`/`serde` для протокола; аудио — `cpal` + `hound`.

## Последствия
+ Нативность, малый overhead, переиспользование проверенного кода.
+ Один бинарь → простой RPM.
− Требуется кросс-сборка Qt+Rust (решается Docker-образом).
