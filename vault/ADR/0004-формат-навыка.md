# ADR-0004: Формат навыка — манифест с kind + файл `.gskill`

**Статус:** принято · **Дата:** 2026-10-11

## Контекст
Нужны расширяемые команды, в т.ч. пользовательские, с возможностью делиться.

## Решение
- Навык = `manifest.json` (+ реализация) с `kind: script|dbus|qml`.
- Слоты передаются как argv/env, без подстановки в shell-строку.
- Экспорт/импорт — самодостаточный файл `.gskill` (имя, команда, метаданные,
  `app_min/app_max`, `sha256`).
- Импорт: файл или URL, ревью + подтверждение (см. [[Безопасность]]).

## Последствия
+ Пользователи создают и шэрят навыки; контроль совместимости по версии.
+ Безопасность по построению (нет shell-инъекций).
− Импорт чужого `script` = исполнение кода → обязательное ревью.
