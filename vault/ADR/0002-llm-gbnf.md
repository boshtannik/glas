# ADR-0002: Извлечение интентов — llama.cpp (GGUF) + GBNF

**Статус:** принято · **Дата:** 2026-10-11

## Контекст
Нужен локальный, on-device маппинг «фраза → готовая команда». Модель должна быть
маленькой и «глупой», без рассуждений.

## Решение
- Инференс через llama.cpp (Rust-обвязка), модель в GGUF.
- Вывод ограничен **GBNF-грамматикой** строго под `{intent, params, reply}|unknown`.
- Низкая temperature, минимальное `n_ctx`.
- Валидация слотов повторяется в `skills`.

## Последствия
+ Никаких «выдуманных» интентов/битого JSON — грамматика гарантирует форму.
+ Полностью offline.
− Нужно подобрать модель/квант под Snapdragon 695; следить за RAM (см. [[Автономность]]).
