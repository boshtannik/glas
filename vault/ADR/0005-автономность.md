# ADR-0005: Автономность — фоновое ожидание «почти ничего не ест»

**Статус:** принято · **Дата:** 2026-10-11

## Контекст
Приложение живёт в фоне (обложка) и должно потреблять минимум, пока от него
ничего не требуется.

## Решение
- В idle — только ядро резидентно; **модели выгружены**.
- Никаких polling/busy-loop; только события (тап обложки, D-Bus).
- `mmap` без `mlock`; явный **unload** по idle-timeout.
- Перед загрузкой модели — проверка влезаемости (static + dynamic) по `MemAvailable`;
  не грузить, если не влезает (защита от OOM).
- Метки моделей `fits/slow/recommended` в каталоге.

## Последствия
+ Низкое потребление в фоне, предсказуемое поведение на слабом устройстве.
+ Не роняем систему из-за тяжёлой модели.
− Первый ответ после простоя — с задержкой на загрузку модели.
