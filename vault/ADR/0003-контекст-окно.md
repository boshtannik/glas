# ADR-0003: Контекст — только скользящее окно

**Статус:** принято · **Дата:** 2026-10-11

## Контекст
Историю нужно передавать в LLM для follow-up-команд, но малая модель деградирует
от длинного контекста и это бьёт по RAM/CPU.

## Решение
- В промпт идёт только последние `K` ходов в компактном виде (`U:` / `A: intent{...}`).
- Старые ходы выпадают безвозвратно (в UI остаются видимы).
- Никакой отдельной «очистки»; механизм один — скользящее окно.
- UX-напоминание пользователю об ограниченной памяти ИИ.

## Последствия
+ Предсказуемый маленький контекст → маленький KV-кэш, быстро и дешево.
+ Честно: пользователь понимает лимит.
− Далёкие отсылки («то, что было 10 команд назад») не работают по определению.
