# Модели и каталог

## Роли моделей
- **asr** — распознавание речи: whisper.cpp `ggml-*.bin` (через `whisper-cli`).
- **tts** — синтез: piper `*.onnx` + `*.onnx.json`.
- **llm** — извлечение интентов: GGUF (llama.cpp).

## Каталог — из интернета (не вшиваем модели руками!)
Каталог приходит **по URL** и кладётся как `~/.local/share/<store>/catalog.json`
(один общий с opencode). В RPM вшит только **пустой** `assets/models.json` как fallback.
Кнопка «Update model catalogs» = скачивание по URL, а не чтение локального файла.

**Решение (14.10.2026):** источник каталога — **Hugging Face** (программа подтягивает
каталог оттуда **позже**; механика HF-загрузки пока не реализована). Кнопка
«Update model catalogs» сейчас лишь перечитывает локальный файл. Формат записей — блюм
opencode (`model_id`/`name`/`lang_id`/`size`/`urls`/`engine`) + `role` + поля
`description`/`quant`/`params`.

**Временно (для проверки прототипа, не коммитится):** в общий
`~/.local/share/harbour-opencode/catalog.json` на телефоне добавлено 5 llm-записей
(Qwen2.5 0.5B/1.5B/3B, SmolLM2 360M/1.7B, `hidden:true`), бэкап `catalog.json.bak-glas-seed`.

## Плашечки влезаемости (бейджи у модели)
У каждой модели в списке — оценка «запустится ли на этом устройстве»:
- 🔴 **не влезет** (по RAM или по свободному месту — нельзя качать/запускать);
- 🟡 **на грани** (запустится с риском, предупреждаем);
- нет плашечки / 🟢 — влезает свободно.

Расчёт — статическая оценка: `need ≈ size + ctx_tokens·bytes_per_token + runtime_overhead`
против `MemAvailable`/`SwapFree` из `/proc/meminfo` (см. [[Автономность]]). Критерии и пороги
красной/жёлтой зоны — зафиксировать.

Упакованный каталог глас (пустой) сейчас перекрывается рабочим каталогом
`harbour-opencode` (182 КБ, 280 моделей STT/TTS, LLM там НЕТ — поэтому страница LLM пустая).

```json

  "models": [

      "id": "whisper-base-ru",

```

## Выбор моделей
- Подходящие для интентов LLM: Qwen2.5-0.5B/1.5B-Instruct, SmolLM2-360M/1.7B,
  Gemma-2-2B (проверить RU-качество и скорость на Snapdragon 695).
- Хранится по одной активной модели на роль.
- Скачивание с прогрессом, отмена, удаление, выбор — как `VoiceModelsPage` в референсе.

## Требования и влезаемость
- В каталоге — ориентировочные требования; реальную оценку «влезет/не влезет» делаем
  на устройстве. См. [[Автономность]].
- Метки: `fits: yes|tight|no`, `slow`, `recommended` — показываем в UI.

## Расположение
`~/.local/share/harbour-glas/models/<role>/<id>/…`

## Движки vs модели
- Движки (`whisper-cli`, `piper`) — в RPM.
- Модели — НЕ в RPM, качаются пользователем.
