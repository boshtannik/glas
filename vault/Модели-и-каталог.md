# Модели и каталог

## Роли моделей
- **asr** — распознавание речи: whisper.cpp `ggml-*.bin` (через `whisper-cli`).
- **tts** — синтез: piper `*.onnx` + `*.onnx.json`.
- **llm** — извлечение интентов: GGUF (llama.cpp).

## Каталог (`assets/models.json`)
Обновляемый по URL реестр (как в референсе dsnote/mason), расширенный ролью:
```json
{
  "schema": 1,
  "models": [
    {
      "id": "whisper-base-ru",
      "role": "asr",
      "lang": "ru",
      "name": "Whisper Base (RU)",
      "size": 142000000,
      "url": "https://…/ggml-base.bin",
      "sha256": "…",
      "tags": ["fits", "recommended"]
    },
    {
      "id": "qwen2.5-0.5b-instruct-q4",
      "role": "llm",
      "lang": "multi",
      "size": 400000000,
      "url": "https://…/qwen2.5-0.5b-instruct-q4_k_m.gguf",
      "sha256": "…",
      "ctx": 2048,
      "tags": ["fits"]
    }
  ]
}
```

## Выбор моделей
- Подходящие для интентов LLM: Qwen2.5-0.5B/1.5B-Instruct, SmolLM2-360M/1.7B,
  Gemma-2-2B (проверить RU-качество и скорость на Snapdragon 695).
- Хранится по одной активной модели на роль.
- Скачивание с прогрессом, отмена, удаление, выбор — как `VoiceModelsPage` в референсе.

## Требования и влезаемость
- В каталоге — ориентировочные требования; реальную оценку «влезет/не влезет» делаем
  на устройстве. См. [[Автономность]].
- Метки: `fits: yes|tight|no`, `slow`, `recommended` — показываем в UI.

## Расположение
`~/.local/share/harbour-glas/models/<role>/<id>/…`

## Движки vs модели
- Движки (`whisper-cli`, `piper`) — в RPM.
- Модели — НЕ в RPM, качаются пользователем.
