# Модели и каталог

## Роли моделей
- **asr** — распознавание речи: whisper.cpp `ggml-*.bin` (через `whisper-cli`).
- **tts** — синтез: piper `*.onnx` + `*.onnx.json`.
- **llm** — извлечение интентов: GGUF (llama.cpp).

## Каталог — живой Hugging Face API (не вшиваем модели руками!)
Кнопка «Update model catalogs» шлёт `llm_catalog_update` → Rust опрашивает **Hugging Face
API** в фоновом потоке и пишет результат в **отдельный** `~/.local/share/<store>/llm_catalog.json`
(общий `catalog.json` opencode со STT/TTS не трогается — иначе приложения затирали бы друг
друга). Формат записей — блюм opencode (`model_id`/`name`/`lang_id`/`size`/`urls`/`engine`)
+ `role` + `description`/`quant`/`params`.

**Механика (14.10.2026, реализовано):**
- Вшит **курируемый список** HF-репозиториев (Qwen2.5 0.5B/1.5B/3B, SmolLM2 360M/1.7B,
  Gemma-2 2B) — стабильные `model_id`, имя, язык, params.
- На репозиторий — GET `huggingface.co/api/models/<repo>/tree/main?recursive=true`; берём
  размер (`lfs.size`), выбираем файл по предпочтению кванта
  (`q4_k_m → q4_k_s → q4_0 → q5_k_m → … → q8_0`, иначе самый маленький); пропускаем
  `mmproj` и шарды `-of-`.
- URL скачивания: `huggingface.co/<repo>/resolve/main/<файл>?download=true`.
- `read_catalog()` предпочитает `llm_catalog.json`, затем общий `catalog.json`, затем вшитый.
- UI: во время обновления — «Updating catalog from Hugging Face…», при ошибке — красная строка.

**Ранний dev-сид:** 5 llm-записей, добавленных вручную в общий `catalog.json` (бэкап
`catalog.json.bak-glas-seed`), теперь игнорируются, как только появится `llm_catalog.json`.

## Плашечки влезаемости (бейджи у модели)
У каждой модели в списке — оценка «запустится ли на этом устройстве»:
- 🔴 **не влезет** (по RAM или по свободному месту — нельзя качать/запускать);
- 🟡 **на грани** (запустится с риском, предупреждаем);
- нет плашечки / 🟢 — влезает свободно.

Расчёт — статическая оценка: `need ≈ size + size/8 + runtime_overhead (160MB)`
против **`MemAvailable` − резерв 512MB** из `/proc/meminfo` (см. [[Автономность]]).
**Swap НЕ учитываем** — на Sailfish это zram (сжатая RAM), реальной ёмкости не добавляет
(при учёте swap 5.3 ГБ телефон выглядел бы как 5.6 ГБ свободных). Пороги:
🔴 `need > usable RAM` или `size > свободный диск`; 🟡 `need > usable·0.8`; иначе 🟢.

Упакованный каталог глас (пустой) сейчас перекрывается рабочим каталогом
`harbour-opencode` (182 КБ, 280 моделей STT/TTS, LLM там НЕТ — поэтому страница LLM пустая).

## Выбор моделей
- Подходящие для интентов LLM: Qwen2.5-0.5B/1.5B-Instruct, SmolLM2-360M/1.7B,
  Gemma-2-2B (проверить RU-качество и скорость на Snapdragon 695).
- Хранится по одной активной модели на роль.
- Скачивание с прогрессом, отмена, удаление, выбор — как `VoiceModelsPage` в референсе.

## Требования и влезаемость
- В каталоге — ориентировочные требования; реальную оценку «влезет/не влезет» делаем
  на устройстве. См. [[Автономность]].
- Метки: `fits: yes|tight|no`, `slow`, `recommended` — показываем в UI.

## Расположение
`~/.local/share/harbour-glas/models/<role>/<id>/…`

## Движки vs модели
- Движки (`whisper-cli`, `piper`) — в RPM.
- Модели — НЕ в RPM, качаются пользователем.
