# Промпты и GBNF

Цель: маленькая и «глупая» модель должна **не думать**, а извлечь из промпта заранее
приготовленную команду, подходящую запросу.

## Системный промпт (компактный)
- Список известных интентов (id + краткое описание + примеры) — сжато.
- Несколько few-shot пар «фраза → JSON».
- Жёсткая инструкция: вернуть **только** JSON.

## Формат вывода
```json
{ "intent": "set_timer", "params": { "duration_seconds": 300 }, "reply": "Таймер на 5 минут" }
```
или
```json
{ "intent": "unknown", "params": {}, "reply": "" }
```

## Ограничение GBNF
- Грамматика llama.cpp (GBNF) описывает ровно ожидаемый JSON и подмножество интентов.
- Модель физически не может выдать невалидный JSON/несуществующий интент.
- Слоты валидируются повторно в `skills` (типы/диапазоны) — см. [[Навыки]].

## Контекст
- В промпт — компактная выжимка последних `K` ходов (см. [[Контекст-и-память]]).
- Каталог интентов и few-shot держим короткими ради экономии окна.

## Локализация
- Промпт/примеры — RU (и EN при необходимости). Язык интерфейса не влияет на грамматику.

## Параметры сэмплинга
- temperature низкая/0; детерминизм важнее «творчества».
- `n_ctx` минимальный, чтобы KV-кэш был маленьким. См. [[Автономность]].
