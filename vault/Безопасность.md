# Безопасность

## Главный риск: импорт чужого кода
Пользовательский `.gskill` может нести произвольный скрипт. Обращаемся с ним как
с установкой чужого ПО.

## Меры
- **Ревью перед импортом:** показать содержимое команды/скрипта, `kind`, флаг `danger`,
  автора; без явного подтверждения — не сохранять.
- **Целостность:** проверка `sha256` из бандла (защита от подмены/обрыва загрузки).
- **Ограничение `kind` для непроверенных:** по умолчанию разрешать `dbus`/`qml`
  (декларативные, ограниченные действия); `script` — только после предупреждения
  «Запускает произвольный код».
- **Никакой подстановки в shell:** слоты идут как argv/env; shell-инъекции невозможны
  по построению. Значения проверяются по типам/диапазонам.
- **Таймауты и kill** для дочерних процессов; запуск в отдельной группе процессов.
- **Права:** пермишены sailjail (микрофон, уведомления и пр.); минимально необходимое.
- **Сеть:** скачивание моделей/навыков — только по https; проверка размеров/hash.

## Что осознанно НЕ делаем
- Не даём LLM свободно формировать shell-команды. Модель выбирает **только** из известных
  интентов/слотов. Никаких «выполни вот эту строку».

## Опасные действия
- Исходящие SMS/звонки, удаление данных и т.п. — помечены `danger`, требуют подтверждения.
