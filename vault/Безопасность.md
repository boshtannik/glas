# Безопасность

> Состояние (2026-10-16): **дизайн** (относится к ещё не реализованным навыкам).
> Ключевое решение — [[ADR-0007-исполнение-навыков]]: **произвольный код не исполняем**.
> Из реализованного смежного: `.desktop` содержит `[X-Sailjail] Sandboxing=Disabled` —
> песочница отключена (вернуть до публикации в Harbour).

## Главный принцип: нет исполнения чужого кода

Навыки — **декларативные** (`dbus` / `open` / композиция builtin) или **builtin на Rust**.
`sh`/`python3`-скрипты из разделяемых файлов **не запускаем**: это вектор для малвари,
и произвольный код **нельзя валидировать** — его можно только песочнить.

Следствие: инъекции невозможны **по построению**. Слоты подставляются **в данные**
(`dbus`-аргумент, URL-шаблон), а не в shell-строку. Нет shell — нет shell-инъекций.

## Декларативное подтверждение (danger)

Решение об опасности принимается **по манифесту**, без «рассуждений модели»:
- `danger: true` → всегда подтверждение;
- политика «опасные действия» (исходящие SMS/звонок, удаление данных) → подтверждение;
- `dbus`/`open`/`builtin`-без-`danger` → обычно без подтверждения.

Подтверждение — **пауза автомата** в `AwaitingConfirmation` (`Event::NeedsConfirmation` →
UI-диалог → `Command::Confirm{approved}`), см. [[ADR-0008-ядро-worker-очередь]].
Во время этой паузы ввод **сужен**: «да/нет» — это ответ; любая другая реплика **не** трактуется
как «да» и **не** запускает подтверждаемое действие — она выводит в **новый навык** (обычная
безопасная маршрутизация: найден/включён → исполняем, иначе → «такого навыка нет / он выключен»).
Так «ответом да/нет» нельзя случайно выполнить другое действие, и вместе с тем нельзя застрять.
См. [[ADR-0011-сессия-и-подтверждение]], [[ADR-0012-диалог-контекст-выход-чтение]].

## Меры

- **Ревью перед импортом:** показать имя, автора, что делает, `do`-композицию, `danger`.
  Без явного подтверждения — не сохранять.
- **Целостность:** проверка `sha256` из `.gskill` (защита от подмены/обрыва загрузки).
- **Сеть:** скачивание моделей/навыков — только по https; проверка размеров/hash.
- **Права:** пермишены sailjail (микрофон, уведомления), минимально необходимое.
- **Каталог интентов** для промпта строится из реестра → модель не может выдумать команду,
  которой нет (см. [[Навыки]]).

## Что осознанно НЕ делаем

- Не даём LLM свободно формировать команды. Модель **только** выбирает известный интент и
  заполняет слоты; слоты повторно валидируются в `Skill::validate`.
- Не исполняем чужой `script`. Не подставляем значения в shell.
- Никакого фонового запуска непроверенного кода.

## Опасные действия

Исходящие SMS/звонки, удаление данных — `danger`, требуют подтверждения.
Как именно слать SMS (DBus/telephony) — открытый вопрос: [[Открытые-вопросы]].

## Если понадобится «код» (позже)

Только **встроенный интерпретатор с capability-API** (`rhai`/`lua`), где мы решаем, какие
функции существуют (`get_time`, `read_sms`, `speak`, …); ни файлов, ни процессов, ни сети
сверх разрешённого. См. [[ADR-0007-исполнение-навыков]].
